# ⚡ 빠른 시작 가이드

## 🎯 5분 안에 실행하기

### 1단계: 의존성 설치 (1분)
```bash
npm install
```

### 2단계: 개발 서버 시작 (30초)
```bash
npm run dev
```

자동으로 브라우저가 열립니다: `http://localhost:3000`

### 3단계: 백엔드 서버 준비 (준비되어 있어야 함)

#### HTTP API 서버 확인
```bash
# 백엔드 서버가 실행 중인지 확인
# 반드시 필요: https://nana-nondefiant-jodee.ngrok-free.dev 에서 실행 중
```

#### WebSocket 서버 확인
```bash
# WebSocket 서버가 실행 중인지 확인
# 반드시 필요: wss://unmuddy-kamala-hendecahedral.ngrok-free.dev 에서 실행 중
```

## 🔌 서버 연결 확인

### 날씨 정보 확인
- 홈 화면 상단의 "오늘의 날씨" 위젯에 온도가 표시되면 ✅

### 실시간 위치 공유 확인
- 지도에서 다른 사용자의 주황색 마커가 보이면 ✅
- 내 위치가 민트색 원으로 표시되면 ✅

## 🆘 문제 발생 시

### "GPS 위치 접근 실패"
→ 브라우저 설정에서 위치 권한 허용

### "날씨 정보 로드 안 됨"
→ 백엔드 API 서버 실행 확인

### "실시간 위치 공유 안 됨"
→ WebSocket 서버 실행 확인

### "포트 3000 이미 사용 중"
```bash
# 다른 포트에서 실행
npm run dev -- --port 3001
```
