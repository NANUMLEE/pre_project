🔍 이 파일이 해주는 일 정리

1. Whisper STT (네 코드 기반)
- process_audio(audio_path)가 음성을 텍스트로 바꾸고
- classify_command(text)로
- 주변 러너 질문 / 이모티콘 전체 전송 / 특정 전송 등 intent 분석 

2. 비즈니스 로직 (TTS 파일에서 가져온 러너/이모티콘 처리)
- 주변 러너 리스트를 받아
- “OOO 등 n명이 뛰고 있습니다”
- “n명에게 이모티콘을 보냈습니다” 같은 문장 생성 

3. Edge TTS (Microsoft TTS)
- 위 문장을 edge-tts로 mp3로 변환하고
- response.mp3 파일로 저장해서 바로 재생 가능하게 함

  🎯 지원하는 기능

  음성 명령어

  | 명령어                 | 기능              |
  |---------------------|-----------------|
  | "주변에 누가 뛰고 있어?"     | 주변 러너 목록 조회     |
  | "주변에 몇 명 있어?"       | 주변 러너 수 확인      |
  | "전체에게 화이팅 보내줘"      | 모든 러너에게 💪 이모티콘 |
  | "김시현한테 하이파이브 보내줘"   | 특정 러너에게 🙌 이모티콘 |
  | "박신혜한테 불꽃 이모티콘 보내줘" | 특정 러너에게 🔥 이모티콘 |

  이모티콘 종류

  - 💪 FIGHTING (화이팅, 파이팅)
  - 🙌 HIGHFIVE (하이파이브)
  - 🔥 FIRE (불꽃)
